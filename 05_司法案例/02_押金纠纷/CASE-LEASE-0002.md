# CASE-LEASE-0002 违约养猫扣押金案

- 案件类型：押金返还纠纷（违约扣减有据型）
- 来源：北京市通州区人民法院《住房租赁案件审判白皮书》十大典型案例之案例七（2025-09-24 发布）
- 来源载体：法院官方发布；本库当前经第三方全文镜像收录，待以法院官方渠道核对
- 来源等级：B
- 来源链接：https://www.szrealtylaw.com/lease/2026/0403/764.html
- 案号：官方发布未附案号
- 裁判日期：官方发布未附（官方摘要未载明上诉情况）
- 地域：北京市 / 通州区

## 案件事实

卫某与北京某物业管理有限公司签订《北京市房屋租赁合同》，明确约定不得在屋内饲养宠物。租赁期满卫某搬离后起诉要求退还押金；公司抗辩卫某租期内养猫构成违约，并提交退租交房时的视频与照片（猫笼、床上有猫毛）。卫某辩称猫是朋友短期寄养，但其所述寄养期间与退租时间间隔较长。

## 争议焦点

1. 合同明确禁养宠物而租客养猫，是否构成违约；
2. 押金可否因此被扣减。

## 合同相关条款

《北京市房屋租赁合同》明确约定承租人不得饲养宠物。

## 法院观点

饲养宠物的特别要求属于出租人维护房源及装修家电的正当利益；退租交房视频照片显示屋内有猫笼、猫毛，卫某“未养猫”的辩解难以采信，即使系朋友寄养也产生了养猫结果，构成违约，应承担违约责任。

## 裁判结果

认定卫某违约，应承担违约责任（官方摘要未披露最终押金数额的精细化处理，但已确立违约扣减的正当性基础）。

## 影响结果的关键事实

- 合同对“禁养宠物”有明确书面约定（决定性）；
- 房东持有退租交房时的视频、照片等直接证据；
- 租客的“寄养”解释与时间线矛盾。

## 适用法律

- LAW-TZ-002（违约责任一般条款）；
- LAW-REG-005 所确立的“约定扣减情形”框架。

## 决定性因素（DECISION_FACTORS）

+ 合同明确约定禁养宠物（决定性）
+ 房东举证充分（视频、照片、时间线）（决定性）
+ 租客行为确实违反约定
0 押金作为履约担保可对应违约责任

## 风险启示

押金不是绝对不能动：合同明确约定的扣减情形 + 房东完成举证，扣减就站得住。对租客的镜像启示是：签约时看清禁养、禁烟、禁止改装等特别约定；对 Skill 的价值是校准“押金一律该退”的朴素认知。

## 关联法律规则

- LAW-REG-005（押金约定扣减情形）
- LAW-TZ-002

## 关联风险
