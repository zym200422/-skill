# RISK-LEASE-001 押金扣除依据不明确

- 状态：正式风险，黄金标准首批
- 版本：V1.0
- 更新日期：2026-09-13
- 模式簇：A. 钱的问题
- 基准等级：🟡 P2
- 最高等级：🔴 P0
- 吸收草案：`RISK-DRAFT-DEPOSIT-001`、`RISK-DRAFT-DEPOSIT-002`、`RISK-DRAFT-DEPOSIT-003`；`RISK-DRAFT-HANDOVER-001` 作为加重因子。

## 一、四层风险模型

| 层级 | 内容 |
| --- | --- |
| L1 现象 | 合同出现押金/保证金/定金式担保款，但缺少返还时间、扣除情形、结算依据或交接程序；也可能写有“有损坏不退”“最终解释权归出租人”等宽泛表述。 |
| L2 法律问题 | 押金约定是否满足行政法规要求；拟扣除事项是否属于约定或正当理由；损失是否属于正常损耗；主张扣减方能否举证因果关系；逾期退还是否有责任抓手。 |
| L3 实际后果 | 租客可能被延迟退还押金、被概括性扣减、承担本属正常损耗的费用，或在退租后缺乏追责依据。 |
| L4 审查动作 | 提取押金数额、支付凭证、返还时间、可扣除事项、计算方式、举证与结算程序、房屋交接方式；再判断是否与违约金或赔偿条款重复。 |

## 二、触发条件

只有在合同存在押金/保证金条款时才进入本规则。

满足任一组即触发：

1. 押金条款缺少“数额、返还时间、扣减押金情形”中任一项。
2. 扣除情形不明确，例如“如有问题可扣除”“根据实际情况扣除”“房屋有任何问题押金不退”“最终解释权归甲方”。
3. 扣除金额、扣款依据或验收结果由出租人单方决定，租客没有异议、复核或结算程序。
4. 有返还时间但没有说明：可扣除什么、按什么标准计算、凭哪些证据结算。
5. 退租交接缺少双方签字的交割单、照片/视频或其他可核验状态记录约定。

## 三、排除与降级条件

### 排除条件

以下情形不触发本规则的核心风险：

1. 合同没有收取押金。
2. 押金条款已明确数额、返还时间、可扣除事项、计算方式、证据/结算方式。
3. 扣除仅限于有合同和证据依据的未付费用、人为损坏、违约赔偿，并明确正常损耗不扣。
4. 双向验收和押金结算程序完整。

### 降级条件

命中触发条件后，如有以下内容可降低风险或缩小提示范围：

1. 押金数额、收款人和账户明确，且能取得收款凭证。
2. 返还时间明确到“验收后 X 日内”。
3. 扣除事项采用清单式列举，而不是概括授权。
4. 明确正常损耗不扣除，损坏由主张方举证。
5. 约定双方共同验收、拍照/视频留档、书面确认扣款项目和金额。
6. 约定逾期返还责任或继续按占用/利息处理，租客有追责抓手。

## 四、加重条件

出现以下任一项升级：

1. “押金不退”“自动没收”“无需证明损失即可扣除”。
2. 扣除标准由出租人单方认定，且租客无异议程序。
3. 把正常损耗写进租客赔偿范围。
4. 无退还期限，或仅写“手续完成后退还”而无时间。
5. 无入住/退租交割单，无照片视频，损坏认定完全依赖事后陈述。
6. 押金与违约金、赔偿金、装修恢复费、清洁费可无限叠加，且没有抵扣关系。

## 五、风险等级判定

| 判定结果 | 等级 |
| --- | --- |
| 未命中触发条件 | 不输出本风险 |
| 基础要素缺失，但没有单方没收式表述 | 🟡 P2 |
| 扣除授权宽泛、无返还期限或无交接证据，且金额可估算 | 🟠 P1 |
| 同时命中“单方决定/概括扣除/正常损耗可扣/无返还期限”中的两项以上，或出现“押金不退、自动没收” | 🔴 P0 |

## 六、法律依据

| ID | 作用 |
| --- | --- |
| LAW-REG-005 | 押金必须在合同中约定数额、返还时间、扣减情形；约定之外无正当理由不得扣减。 |
| LAW-LEASE-007 | 承租人按约定方法或租赁物性质使用造成的损耗，不承担赔偿责任。 |
| LAW-LEASE-017 | 不当使用致损需要“未按约定方法/性质使用”和因果关系，主张方应举证。 |
| LAW-TZ-005 | 违约金以约定为前提；过高可请求适当减少。用于审查押金变相没收和逾期责任。 |
| GF—2025—2614 第六条、第八条、第十五条 | 官方示范文本把押金、双向验收和违约标准作为可填写项，是合同基线。 |

## 七、案例依据

| 案例 | 对规则的支撑 |
| --- | --- |
| CASE-LEASE-0001 | 房东不能证明地板/热水器损坏系租客不当使用所致，无权扣押金；证明“损坏—行为”因果关系很关键。 |
| CASE-LEASE-0002 | 不利租客对照：合同明确禁养宠物，证据充分时，违约扣减有据。说明“明确约定 + 证据”可以支持扣款。 |
| CASE-LEASE-0003 | 只写返还时间不等于一定有逾期违约金；逾期退押金的违约金须有明确约定。 |
| CASE-LEASE-0007 | 水管老化属于房东维修义务范围，租客无过错时押金应退；不能用“房里坏了”概括扣款。 |

## 八、审查问题清单

Skill 至少逐项提取或追问：

1. 押金金额是多少？收款人是出租人、企业、中介还是平台？
2. 是否有收款凭证？
3. 返还时间是否明确？是“退房当日”“验收后 7 日内”，还是空白？
4. 可扣除事项是否清单化？是否包括未付租金、水电燃气物业费、人为损坏、违约赔偿？
5. 每项扣除如何计算？是否需要发票、收据、维修报价、物业证明或双方确认？
6. 是否明确正常损耗不扣？
7. 入住和退租如何验收？是否签署交割单？是否拍照/视频？
8. 扣款有争议时，租客能否要求说明、复核、第三方评估或依法处理？
9. 押金能否抵扣最后一期租金或违约金？抵扣顺序是否明确？
10. 押金扣除与违约金是否重复计算？

## 九、用户后果与潜在损失

基础公式：

```text
押金暴露 = 押金数额
+ 合同约定的可叠加清洁费/维修费/违约金
- 明确可抵扣、有凭据且合理的项目
```

说明：

1. 如果合同只写“损坏可扣”而没有标准，Skill 应输出“最高可能争议到全部押金”，不要写成“一定会扣押金”。
2. 如果没有退还时间，潜在损失还包括时间成本和催讨成本，但不宜折算成固定金额。
3. 如果押金与违约金并存，必须检查是否可抵扣、是否重复计算。

## 十、建议措施

签约前要求补充或改写：

1. 写明押金金额、收款人和账户，并要求收款当日出具凭证。
2. 写明“验收合格后 X 日内退还至租客指定账户”。
3. 以清单列举可扣除事项，例如欠付租金、水电燃气物业费、租客人为损坏、双方确认的违约金。
4. 写明扣除需要对应凭证、照片、维修单、发票或第三方记录。
5. 明确正常损耗不扣除，损坏及因果关系由出租人举证。
6. 约定入住、退租共同验收，签署交割单，并拍摄带日期的照片/视频。
7. 写明押金与违约金、赔偿金的抵扣顺序，避免重复收取。
8. 约定逾期不退的合理责任，例如继续计息、每日违约金或可依法主张损失。

## 十一、Skill 输出示例

### P2 示例

🟡 **押金条款需要补充**

合同约定了押金，但没有明确出租人可以因哪些具体事项扣除，以及扣除后如何结算。

建议签约前明确：可扣除事项、扣除计算标准、房屋损坏认定方式、退还时间。

### P0 示例

🔴 **押金条款存在单方处置风险**

合同写明“房屋有任何问题押金不退”，没有退还期限，也没有约定损坏认定和结算依据。这会把正常损耗、房东未维修问题和租客过错混在一起。

理论最高争议金额：押金 2000 元，外加合同中未设上限的维修/清洁费。

建议改为：除租客欠付费用或经证据证明的人为损坏外，出租人应在双方验收合格后 7 日内全额退还押金；正常损耗不扣除，扣款需提供凭证。

## 十二、边界

1. 明确约定“租客违约养宠物可扣减”不一定是坏条款；必须同时检查证据和扣减比例。
2. 押金不是不能扣，而是扣除必须有约定、有正当理由、有证据。
3. 本规则不判断房东是否实际违约，也不替代退租时的证据收集。
