# RISK-LEASE-003 维修责任概括性转嫁

- 状态：正式风险，黄金标准首批
- 版本：V1.0
- 更新日期：2026-09-13
- 模式簇：B. 房的问题
- 基准等级：🟡 P2
- 最高等级：🔴 P0
- 吸收草案：`RISK-DRAFT-REPAIR-001`、`RISK-DRAFT-REPAIR-002`；`RISK-DRAFT-EVIDENCE-001` 作为加重因子。

## 一、四层风险模型

| 层级 | 内容 |
| --- | --- |
| L1 现象 | 合同写“房屋及所有设施设备发生故障均由乙方负责维修”“一切损坏由乙方负责”，或只写租客责任而不写报修、维修期限、费用负担和原因区分。 |
| L2 法律问题 | 出租人原则上负维修义务但允许另行约定；自然老化、正常损耗、租客过错、不当使用和房屋自身瑕疵应分别归责；影响使用时是否有减租或延租救济。 |
| L3 实际后果 | 租客可能自费维修房屋主体、老化设备或安全设施，被扣押金，或在房屋不适租时仍继续付租。 |
| L4 审查动作 | 判断损坏对象、原因、证据、报修流程、维修期限、费用承担、可否自修报销、是否影响居住，以及是否涉及消防燃气等安全设施。 |

## 二、触发条件

满足任一组即触发：

1. 维修责任概括性归承租人，例如“一切维修均由乙方负责”“所有设施故障由乙方承担”。
2. 条款不区分自然老化、正常损耗、质量瑕疵和租客过错。
3. 把房屋主体结构、共用设施、水电燃气主线、消防喷淋/烟感等安全设施的一般维修责任全部交给租客。
4. 只写租客要维修，不写出租人报修响应期限。
5. 租客自行维修没有事先告知、费用凭证和报销机制。
6. 房屋不适租、房东不维修与押金扣除直接挂钩。

## 三、排除与降级条件

### 排除条件

以下条款通常不触发本规则：

1. 只约定“因租客人为损坏、不当使用造成的维修/赔偿责任由租客承担”。
2. 出租人承担房屋主体结构、固定设施、自然老化和非租客过错故障的维修。
3. 双方明确报修渠道、响应期限、紧急维修流程。
4. 因出租人未及时维修导致租客自行维修的，费用凭凭证由出租人承担。
5. 维修影响正常使用的，明确减租、延租或其他补偿。

### 降级条件

1. “租客负责日常维护”且范围限于灯泡、水龙头垫片等低价值易耗件。
2. 明确人为损坏归租客，自然损耗归出租人。
3. 写明报修电话/微信、响应时间、上门期限和紧急联系人。
4. 写明出租人不维修时租客可自行维修并凭凭证报销。
5. 写明因维修影响使用的租金减免或租期顺延。

## 四、加重条件

1. 概括性使用“所有”“一切”“无论任何原因”。
2. 正常损耗、自然老化被列入租客赔偿范围。
3. 消防、燃气、电路、燃气热水器、烟感/喷淋等安全设施维修或更换责任全部给租客。
4. 房东不维修时，租客也不能自修报销、减租或解约。
5. 维修费用直接从押金扣除，且不需要凭证。
6. 无第三方原因记录要求，损坏原因完全由房东事后认定。

## 五、风险等级判定

| 判定结果 | 等级 |
| --- | --- |
| 只约定人为损坏由租客负责 | 不输出风险 |
| 维修分工缺失，或“日常维护”范围不清 | 🟡 P2 |
| 概括转嫁、无报修期限或自修不能报销 | 🟠 P1 |
| 覆盖房屋主体/水电燃气主线/消防燃气等安全设施，或导致房屋可能无法正常居住 | 🔴 P0 |

## 六、法律依据

| ID | 作用 |
| --- | --- |
| LAW-LEASE-006 | 出租人应在租期内保持房屋符合约定用途。 |
| LAW-LEASE-007 | 承租人按约定方法或租赁物性质使用造成的损耗不承担赔偿责任。 |
| LAW-LEASE-008 | 出租人原则上承担维修义务，但当事人另有约定；约定不能使房屋根本不适租。 |
| LAW-LEASE-009 | 租客可请求出租人在合理期限内维修；出租人不维修时，租客可自修并要求负担费用；影响使用可减租或延租。 |
| LAW-LEASE-017 | 未按约定方法或租赁物性质使用致损的，出租人可解除并请求赔偿；需证明不当使用与损失的因果关系。 |
| LAW-LEASE-018 | 租客也应妥善保管租赁物；保管不善造成毁损灭失应赔偿。 |
| GF—2025—2614 第十条 | 官方示范文本要求出租人承担正常使用损坏的维修，并规定自修报销和拒修解约路径。 |

## 七、案例依据

| 案例 | 对规则的支撑 |
| --- | --- |
| CASE-LEASE-0007 | 水管老化漏水属于设施自然老化，归出租人维修义务范围；租客无过错时押金应退。 |
| CASE-LEASE-0008 | 不利租客对照：将衣物晾在消防喷淋导致启动漏水，租客不当使用安全设施，承担合理损失赔偿。维修风险不能只保护租客，原因决定责任。 |

## 八、审查问题清单

1. 故障对象是什么？属于房屋主体结构、水电燃气主线、固定设施、家具家电，还是租客自带物品？
2. 故障原因是自然老化、产品质量、前租客遗留、房东未维修、不可抗力，还是租客使用不当？
3. 有没有入住照片/视频、维修单、物业记录、报警记录或第三方检测记录？
4. 合同是否区分“人为损坏”与“正常损耗”？
5. 报修渠道是什么？出租人应在多少小时内响应？
6. 紧急漏水、断电、燃气泄漏如何处理？
7. 出租人不维修时，租客能否自行维修并凭凭证报销？
8. 维修影响居住时，是否减租、延租或提供替代住宿？
9. 消防喷淋、烟感、燃气设施、电路是否被要求“租客负责”？
10. 押金是否会因维修费用被扣除？有无凭证和上限？

## 九、用户后果与潜在损失

潜在暴露包括：

```text
租客可能承担的维修费/赔偿金
+ 押金中被主张的维修扣款
+ 因无法正常居住期间的租金争议
```

约束：

1. 只有因果关系成立且损失有凭证的项目才可能获得支持。
2. 安全设施、楼下漏水、邻里财产损失可能超过押金金额，不能按“押金扣完即结束”理解。
3. 如果原因无法确定，应输出“需要第三方记录/维修定性”，不要直接判定租客担责或房东担责。

## 十、建议措施

1. 把“所有维修由乙方负责”改为三层分工：房屋主体与固定设施归出租人；自然损耗和质量瑕疵归出租人；租客人为损坏和不当使用造成的损失归租客。
2. 明确报修渠道和响应期限，例如一般故障 48 小时内响应，紧急漏水、断电、燃气问题 24 小时内处理。
3. 写明出租人逾期不维修时，租客可自行维修并凭发票/收据从租金中抵扣或要求报销。
4. 写明维修影响正常使用的，按日减租或延长租期。
5. 明确消防、燃气、电路、烟感/喷淋等安全设施不得由租客自行改动，故障应报专业维修并区分原因。
6. 入住时拍摄水电表、家具家电、墙面地板、卫生间和厨房状态；发现故障当场写入交割单。
7. 损坏发生后立即拍照/录像，保存聊天记录、维修单、物业或第三方说明。

## 十一、Skill 输出示例

### P1 示例

🟠 **维修责任被概括性转移给租客**

合同写明“房屋及所有设施设备发生故障均由乙方负责维修”，但没有区分自然老化、正常损耗、房屋自身问题和租客人为损坏，也没有约定报修期限和自修报销。

这可能导致水管老化、家电质量故障或房东未处理的房屋问题由你付费。建议改为：出租人承担房屋及固定设施的非租客过错维修；因租客不当使用造成的损坏由租客负责；出租人逾期不维修，租客可自修报销；维修影响使用的减租或延租。

### P0 示例

🔴 **安全设施维修责任不能全部转嫁给租客**

合同要求租客负责包括消防喷淋在内的所有设施维修，但没有写原因区分和维修资质要求。消防、燃气和电路问题不仅关系费用，还关系人身安全。

建议签约前删除或改写：安全设施不得自行改动；故障由出租人安排专业维修；因租客不当使用造成的损失由租客承担，但需凭证据和因果关系确定。

## 十二、边界

1. “乙方维修”不是当然无效；民法典允许当事人另有约定，关键是范围、原因和救济是否公平可执行。
2. 租客也有妥善保管义务，漏水不报、明知风险不处理可能扩大责任。
3. 本规则不预设哪一方一定赔偿；输出必须保留“原因 + 证据”两个条件。
