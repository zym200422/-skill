# RISK-LEASE-002 提前退租与违约金责任过重

- 状态：正式风险，黄金标准首批
- 版本：V1.0
- 更新日期：2026-09-13
- 模式簇：C. 合同的问题
- 基准等级：🟠 P1
- 最高等级：🔴 P0
- 吸收草案：`RISK-DRAFT-BREACH-001`、`RISK-DRAFT-BREACH-002`、`RISK-DRAFT-BREACH-003`；`RISK-DRAFT-LOSS-001` 作为损失审查因子。

## 一、四层风险模型

| 层级 | 内容 |
| --- | --- |
| L1 现象 | 合同约定提前退租须支付剩余租金全部/部分、高额违约金、没收全部押金、继续支付空置损失；或完全没有通知期、违约金标准和交接程序。 |
| L2 法律问题 | 违约责任是否成立；违约金是否过分高于实际损失；押金与违约金关系；房东是否履行止损义务；租客是否享有法定或约定解除事由。 |
| L3 实际后果 | 租客可能同时面对押金损失、高额违约金、空置损失索赔和剩余租金争议，且缺少退出通道。 |
| L4 审查动作 | 读取租期、剩余租金、违约金比例或金额、通知期、免责事由、押金抵扣、空置损失口径、房东违约和房屋重新出租安排。 |

## 二、触发条件

满足任一组即触发：

1. 提前退租责任采用“剩余租期租金的 100%/200%”“全部剩余租金”“固定高额违约金”等口径，且没有上限或酌减说明。
2. “提前退租”直接绑定“没收全部押金”。
3. 违约金与空置损失、剩余租金、中介费、律师费可并列表述，但没有抵扣和凭据规则。
4. 提前退租条款没有通知期、违约金计算方式、押金处理和退房交接程序。
5. 合同只写“乙方不得提前退租，否则承担全部责任”，没有可执行口径。

## 三、排除与降级条件

### 排除条件

以下情形通常不触发“责任过重”：

1. 合同没有提前退租违约金安排，且也不存在“全部责任”式概括条款。
2. 责任清晰、合理，并明确押金抵扣关系。
3. 条款允许法定解除或出租人违约时免责。
4. 违约金仅按固定、可预期的标准计算，例如已住 6 个月后提前 30 日通知可按 1 个月租金结算。

### 降级条件

1. 明确提前 X 日书面通知后可解约。
2. 违约金按固定月数租金计算，而不是按全部剩余租期计算。
3. 违约金从押金中抵扣，多退少补。
4. 明确“违约金已涵盖空置损失，房东应积极重新出租”。
5. 列明租客可免责或解除的情形：房屋危害安全健康、房东不能保持适租、无权出租、不可归责于租客的原因等。
6. 明确双方交接和费用结算程序。

## 四、加重条件

1. 违约金按剩余租期 100% 以上计算，或没有上限。
2. “没收全部押金”与高额违约金并用。
3. 违约金、空置损失、剩余租金重复计算。
4. 空置损失不设期限，也不要求房东止损或重新出租。
5. 无提前通知要求，或任何提前退租都构成重大违约。
6. 未区分房东违约、房屋不适租、安全问题、无权出租等法定或正当退出事由。
7. 拒绝交接或不接受退房，导致损失持续扩大。

## 五、风险等级判定

| 判定结果 | 等级 |
| --- | --- |
| 有提前退租安排，但责任、通知期和押金处理完整合理 | 不输出风险，或仅 🔵 P3 提醒保留证据 |
| 责任完全未约定，或表述过于笼统 | 🟡 P2 |
| 有高额违约金/没收押金/重复索赔信号 | 🟠 P1 |
| 同时满足“高额或无上限 + 押金没收 + 重复索赔/无止损”中两项以上，或潜在暴露超过 6 个月租金 | 🔴 P0 |

## 六、法律依据

| ID | 作用 |
| --- | --- |
| LAW-TZ-002 | 违约责任以不履行或不按约定履行为起点，但具体范围仍需审查。 |
| LAW-TZ-003 | 租赁这类持续给付债务不适于强制履行；履行僵局时违约方可请求司法终止，但违约责任不免除。 |
| LAW-TZ-004 | 损失赔偿以实际损失和订约时可预见范围为限。 |
| LAW-TZ-005 | 违约金以约定为前提；过分高于损失可请求适当减少。 |
| LAW-TZ-006 | 守约方应采取适当措施防止损失扩大；怠于止损的扩大部分不能转嫁给违约方。 |
| LAW-TZJS-001 | 司法终止的合同权利义务终止时间需结合个案认定。 |
| LAW-REG-005 | 除约定情形外，出租人无正当理由不得扣减押金。 |
| GF—2025—2614 第十五条 | 官方示范文本要求填写提前解约通知期、违约金标准和可预见损失上限，是违约条款基线。 |

## 七、案例依据

| 案例 | 对规则的支撑 |
| --- | --- |
| CASE-LEASE-0004 | 违约金已弥补损失时，合理止损期外的空置损失不支持；房东/出租人也要止损。 |
| CASE-LEASE-0005 | 不利租客对照的反面制约：提前退租 200% 违约金被法院酌减；违约金足以弥补损失时押金应退。 |
| CASE-LEASE-0006 | 责任完全未约定时，法院可能结合履行僵局、实际腾退和过错酌定损失；本案以六个月租金作为参考基准。 |

## 八、审查问题清单

1. 租期起止日期是什么？签约时剩余租期是多少？
2. 月租金、押金、支付周期分别是多少？
3. 提前退租需要提前多少日通知？通知方式是否明确？
4. 违约金是固定金额、固定月数租金，还是按剩余租金比例计算？
5. 是否以剩余租期租金为基数？比例是多少？是否有上限？
6. 押金能否抵扣违约金？抵扣后是否多退少补？
7. 空置损失、重新出租中介费、装修恢复费、律师费是否会另行主张？
8. 违约金与实际损失是否重复计算？
9. 房屋是否存在危害安全健康、无法正常使用、无权出租、房东违约等法定或正当退出事由？
10. 房东是否必须重新出租？是否有止损期？
11. 退租时如何交接？钥匙、水电燃气、物品和费用如何结算？

## 九、用户后果与潜在损失

按剩余租金比例计算时：

```text
违约金暴露 = 月租金 × 剩余租期月数 × 合同约定比例
理论最大暴露 = 违约金暴露 + 可能被扣押的押金
+ 合同明确约定且可能另行主张的空置损失/费用
```

示例：

```text
月租金：1800 元
剩余租期：8 个月
约定：提前退租支付剩余租期 50% 的租金
押金：1800 元

违约金暴露 = 1800 × 8 × 50% = 7200 元
理论最大暴露 = 7200 + 1800 = 9000 元
```

输出约束：

1. “200%”如果没有明确基数，必须先追问是“月租金的 200%”还是“剩余租期租金的 200%”，两者差距可能非常大。
2. 空置损失只有在真实发生、合理且未超过止损期时才可能获得支持，不能直接按全部剩余租期累加。
3. 法院可酌减过高违约金，但 Skill 不应向用户保证一定酌减到某个数字。

## 十、建议措施

1. 把“剩余租期租金的 100%/200%”改为固定、可预期标准，例如提前 30 日通知后支付 1 个月租金。
2. 删除“没收全部押金”，改为“押金抵扣违约金和未付费用后多退少补”。
3. 写明违约金已涵盖空置损失，避免重复索赔。
4. 要求出租人合理止损；房屋重新出租后，未发生的空置期不再计损。
5. 增加免责和解除事由：房屋危害安全健康、房东不能保持适租、无权出租、不可抗力或不可归责于租客的原因。
6. 明确退租通知方式、交接时间、水电燃气结算和物品搬离程序。
7. 保留房东违约、报修记录、房屋问题照片/视频，防止“租客违约”被单方面扩大解释。

## 十一、Skill 输出示例

### P2 示例

🟡 **提前退租规则需要确认**

合同提到可以退租，但没有写提前通知期、违约金计算方式、押金抵扣和交接程序。一旦发生退租争议，双方容易对“应赔多少”产生分歧。

请补充：提前 30 日书面通知；违约金按 1 个月租金计算；押金抵扣后多退少补；双方签署退租交接单。

### P0 示例

🔴 **提前退租责任明显过重**

合同约定提前退租支付剩余租期 100% 的租金，并没收全部押金，且未设上限、未写房东止损义务。按月租 1800 元、剩余 8 个月估算，仅违约金暴露就约 14400 元，加上押金后理论暴露约 16200 元。

这一条建议重点协商：改为固定违约金或提前通知后按 1 个月租金计算；押金抵扣后多退少补；违约金已涵盖空置损失；房东应合理重新出租。

## 十二、边界

1. 高额违约金条款不是当然无效，法院通常在当事人请求且过分高于损失时调整。
2. 租客单方违约不因“合同苛刻”而自动免责。
3. 房东违约或房屋存在法定解除事由时，责任方向可能反转，Skill 必须先核查事实和证据。
