# 司法案例库（阶段 2）

- 版本：V1.0 试点（2026-09-13）
- 目标：把租房纠纷沉淀为“事实 → 条款 → 争议焦点 → 法院判断 → 结果 → 决定性因素 → 风险规则”的案例卡片，供未来 Skill 做类比推理。
- 试点规模：10 个高质量案例（押金返还 3、提前退租 3、维修纠纷 2、转租二房东 2）。目标规模 100~300 个，试点结构验证通过后批量扩展。

## 来源与分级

| 等级 | 范围 | 本库现状 |
| --- | --- | --- |
| A | 法院官网 / 最高法官网 / 法院系统政务号发布的案例 | 海淀法院官网、山东法院网站群、最高法官网转发、澎湃政务号（法院认证账号）、北京政法网 |
| B | 人民法院案例库、公报、法院官方发布典型案例 | 通州法院十大典型案例（现经律所网站全文镜像收录，待官方渠道核对） |
| C | 律师文章、法律数据库整理 | 暂无 |
| D | 新闻报道（含转述法院审结案件） | 仅存线索池，不作为规则结论依据 |
| E | 用户社区经验 | 仅作检索线索，不入库 |

原则：D/E 级只能回答“值得检索什么”，案例卡片的事实与裁判观点必须来自 A/B 级原文；引用时保留来源链接与获取日期。

## 案例卡片格式

每个案例一个文件，统一字段：

CASE-LEASE-XXXX 案件标题 / 案件类型 / 来源（法院 + 载体 + 链接 + 日期 + 等级）/ 案号 / 裁判日期 / 地域 / 案件事实 / 争议焦点 / 合同相关条款 / 法院观点 / 裁判结果 / 影响结果的关键事实 / 适用法律 / 决定性因素（DECISION_FACTORS，用 +/-/0 标注方向）/ 风险启示 / 关联法律规则（LAW-*）/ 关联风险（RISK-DRAFT-*，阶段 4 转正）
