# 租房合同 Skill 知识工程

目标：把“租房防坑”从经验谈升级为可检索、可引用、可推理的知识库，最后才编写 Skill Prompt。Skill 的每个风险结论都必须能回溯到规则 ID 和原始条文。

## 仓库范围

本仓库只保存可复用知识资产：法律规则、司法案例卡、风险规则、官方示范文本和结构化审查规则。真实当事人合同、照片、身份证号、付款码和私人文书不入库。

## 路线图

1. 阶段 1 权威法律知识库（V1.1，含案例试点回填）
2. 阶段 2 真实案例库（试点 10 案已完成，目标 100~300 个）
3. 阶段 3 租房风险模式库（黄金标准 4 条 + Step 7 转正 1 条）
4. 阶段 4 合同条款库（CLAUSE-XXX）
5. 阶段 5 审查规则库与测试集
6. 阶段 6 编写 Skill Prompt

## 规则条目格式（LAW-*）

规则ID / 来源 / 条文 / 条文原文 / 主题 / 规则 / 适用场景 / 关键词 / 对租客意义 / 关联风险（阶段 4 回链）

## 编码约定

- LAW-LEASE-XXX：民法典租赁合同章规则
- LAW-REG-XXX：住房租赁条例规则
- LAW-TZ-XXX：民法典合同编通则规则
- LAW-TZJS-XXX：合同编通则司法解释规则
- LAW-ZLJS-XXX：城镇房屋租赁司法解释规则
- CASE-XXX：司法案例（阶段 2）
- RISK-XXX：风险规则（阶段 3）
- CLAUSE-XXX：合同条款（阶段 5）

## 可信度等级

A 法律法规/官方文件；B 法院裁判/官方案例；C 律师专业文章；D 主流媒体报道；E 普通用户经验；F 营销文章。E/F 只能提出假设，不能作为结论依据。
