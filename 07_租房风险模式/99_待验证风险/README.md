一个因子或候选要升级为一级风险，至少满足：

1. 有可识别的合同触发条件，而不是纯事实争议。
2. 有排除和降级条件，避免关键词误报。
3. 有既有法律规则或示范文本基线支撑。
4. 有至少一个 A/B 级案例支撑，或已明确标注为待验证线索。
5. 能定义独立的审查动作和用户后果。
