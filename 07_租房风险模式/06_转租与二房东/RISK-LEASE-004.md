# RISK-LEASE-004 二房东/转租链条断裂

- 状态：正式风险，黄金标准首批
- 版本：V1.0
- 更新日期：2026-09-13
- 模式簇：D. 权利的问题
- 基准等级：🔴 P0
- 吸收草案：`RISK-DRAFT-SUBLET-001`、`RISK-DRAFT-SUBLET-002`。

## 一、四层风险模型

| 层级 | 内容 |
| --- | --- |
| L1 现象 | 收款人不是产权人；合同名称可能是“转租”“代理”“托管”“资产管理”；租客拿不到上游租赁合同、产权/出租权证明或书面转租同意；转租期超过上游剩余租期；二房东企业不走资金监管账户。 |
| L2 法律问题 | 出租人是否有权出租；转租是否经原出租人同意；转租期限是否超过上游剩余租期；上游合同解除/到期后租客是否构成逾期占用；收付款是否受住房租赁资金监管约束。 |
| L3 实际后果 | 租客可能被真正房东清退，仍需支付逾期占用费，同时难以追回押金和预付租金；居住稳定性直接崩断。 |
| L4 审查动作 | 核验收款人身份、产权/合法出租权证明、上游租期、书面转租同意、合同期限、资金监管账户、企业身份和付款周期；评估链条断裂后的即时自救路径。 |

## 二、触发条件

与“非产权人”签约时，任一项命中即触发：

1. 对方不能提供产权证、不动产权属查询记录或其他合法出租权证明。
2. 对方是承租人/受托管理人，但没有上游租赁合同。
3. 没有原出租人同意转租的书面文件，也没有可在签约前直接向原出租人核实的安排。
4. 二房东合同期限超过上游合同剩余租期。
5. 对方以企业或规模化转租经营方式收租，但不提供住房租赁资金监管账户信息。
6. 对方拒绝说明真实身份，或要求把押金/租金付到与合同主体无关的个人账户。
7. 只有口头保证“房东知道/同意”，没有任何可留存证据。

## 三、排除与降级条件

### 排除条件

以下情形不触发本规则：

1. 出租人就是产权人，身份和权属证明一致。
2. 受托出租人提供了授权委托书、产权证明和可核验联系方式。
3. 转租人提供了上游租赁合同、原出租人书面同意或合同明确允许转租的条款。
4. 本合同租期不超过上游剩余租期。
5. 从事转租经营的企业提供并公示资金监管账户，租金押金按监管要求收付。

### 降级条件

仅在链条核心要素齐全但仍有残余不确定时适用：

1. 已通过电话、视频或现场方式由原出租人确认同意，并保留记录。
2. 上游剩余租期比本合同多出合理缓冲。
3. 押金和租金付款对象与合同主体一致，有可追踪支付凭证。
4. 合同明确上游合同解除后的交接、退款和安置责任。
5. 对方是住房租赁企业并配合提供监管账户和经营信息。

## 四、加重条件

1. 拒不出示产权/上游合同/转租同意。
2. 合同主体、收款账户、微信收款人、中介说法不一致。
3. 要求年付、半年付或大额预付。
4. 上游剩余租期短于本合同，或上游租期不明。
5. 对方名下疑似批量收房转租，却以“个人”名义规避企业监管。
6. 有群租、隔断、频繁换锁、频繁更换管理人员等迹象。
7. 平台或中介代收代付租金押金。

## 五、风险等级判定

本规则采用“核心链条缺口即高危”的基准。

| 判定结果 | 等级 |
| --- | --- |
| 产权人直租且身份/权属一致 | 不输出本风险 |
| 委托出租链条完整，仅有签约细节待补 | 🟡 P2 |
| 转租授权、上游合同或期限存在小范围缺口，可签约前补验 | 🟠 P1 |
| 缺少上游合同、书面同意、权属证明、期限覆盖或资金监管中的任一核心项 | 🔴 P0 |

## 六、法律依据

| ID | 作用 |
| --- | --- |
| LAW-LEASE-010 | 承租人经出租人同意才能转租；未经同意转租，出租人可以解除合同。 |
| LAW-LEASE-019 | 转租期限超过承租人剩余租期的，超过部分对出租人不具有法律约束力。 |
| LAW-LEASE-012 | 第三人主张权利导致租客无法使用收益的，可请求减租或不付租金，但应及时通知出租人。 |
| LAW-LEASE-013 | 因权属争议等原因且非因租客原因无法使用时，租客可依法解除。 |
| LAW-REG-004 | 出租人应出示身份证明、权属证书或其他合法出租权材料，并配合租客核验。 |
| LAW-REG-007 | 从事转租经营的住房租赁企业应设立并公示资金监管账户，通过该账户办理租金押金收付。 |
| LAW-REG-008 | 自然人转租达到经营规模的，适用住房租赁企业规定。 |
| LAW-REG-015 | 转租企业未按规定使用资金监管账户，可被责令改正并处罚款。 |
| LAW-ZLJS-003 | 上游合同无效、到期或解除后，负有腾房义务的次承租人逾期不搬，出租人可直接请求支付占用使用费。 |

## 八、审查问题清单

1. 收款人、合同甲方和实际带看人分别是谁？
2. 对方是产权人、产权人的受托人、承租人转租、托管企业，还是中介？
3. 能否提供身份证/营业执照、产权证或权属查询记录？
4. 如果是转租：上游租赁合同的租期、租金、转租条款和解除条件是什么？
5. 是否有原出租人书面同意转租？能否直接向原出租人核实？
6. 本合同起止日期是否完全落在上游剩余租期内？
7. 对方是住房租赁企业还是个人？是否达到应适用企业监管的规模？
8. 企业转租是否提供资金监管账户？账户名称是否与合同主体一致？
9. 押金、租金、服务费分别付给谁？是否有发票、收据和可追踪凭证？
10. 上游合同解除或对方跑路时，押金和剩余租金由谁退还？租客能否与真正房东换签？
11. 房屋是否存在群租、隔断、消防隐患或非居住空间改住？

## 九、用户后果与潜在损失

```text
一次性暴露
= 已付押金 + 已预付租金 + 未消费服务费

持续暴露
= 真正房东主张的逾期占用费（按日计算）
+ 搬家、临时住宿、物品搬运等损失
+ 因清退导致的误工和履约损失
```

输出约束：

1. 如果上游剩余租期可查，应计算“本合同保障期 = 上游剩余租期 - 本合同已过天数”。
2. 如果上游租期不可查，必须提示“本合同承诺的租期可能部分或全部不受真正房东约束”。
3. D 级新闻线索只能用于说明风险和检索方向，不能写成法院已确认的一般规则。

## 十、建议措施

签约前：

1. 要求出示出租人身份证/营业执照、产权证或权属查询记录。
2. 如果是二房东，要求提供上游租赁合同、允许转租条款或原出租人书面同意。
3. 直接向原出租人核实同意、租期和收款安排，并保留通话录音、聊天记录或三方确认。
4. 核对本合同租期不超过上游剩余租期；超出部分应单独写清风险和退款机制。
5. 企业转租要求提供资金监管账户，拒绝把大额租金付到个人账户。
6. 优先月付或短周期支付，避免年付和半年付。
7. 写明链条断裂时的解除、退押、退剩余租金和搬离缓冲期。
8. 保存全部合同、付款记录、聊天记录、房屋状态照片和对方身份材料。

发现链条断裂后：

1. 立即停止向无法履约的二房东继续支付大额租金。
2. 与真正房东书面确认房屋状态、占用费起算和换签/腾退方案。
3. 不要消极拖延腾退；如确需时间，主动协商合理期限并留证。
4. 同时向二房东主张解除、退款和损失，保留起诉所需证据。

## 十一、Skill 输出示例

### P0 示例一：无权转租

🔴 **二房东链条缺少核心授权**

合同甲方不是产权人，且你目前没有上游租赁合同和原出租人同意转租的书面材料。根据转租规则，未经真正出租人同意，出租人可以解除上游合同；上游合同解除后，你如果逾期不腾退，还可能被直接主张占用使用费。

理论暴露包括：押金、已预付租金，以及按日计算的占用费和搬家损失。

签约前必须补齐：产权/合法出租权证明、上游租赁合同、原出租人书面同意，并核对本合同租期不超过上游剩余租期。无法核验前，不建议支付大额租金。

### P0 示例二：企业二房东资金风险

🔴 **转租经营资金未进入可核验监管路径**

对方以企业方式批量转租，但只提供个人银行账户收款，且要求一次支付一年租金。住房租赁条例要求从事转租经营的企业使用并公示资金监管账户。

请要求对方提供监管账户信息，并将付款主体、合同主体和收款账户保持一致。无法提供时，应改为月付并重新评估签约。

## 十二、边界

1. 二房东不必然是骗局；有上游合同、书面同意、期限覆盖和资金监管的合法转租可以接受。
2. 合同叫“资产管理”“托管”“服务协议”不决定性质，要审查是否实际交付房屋并支付固定收益/租金。
3. 产权人直租仍可能有抵押、查封、群租、安全等问题，不能因本规则未触发就停止其他审查。
