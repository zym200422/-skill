# 湖南与河南两份合同验证报告

- 测试日期：2026-09-13
- 测试依据：`07_租房风险模式` 中 `RISK-LEASE-001` 至 `RISK-LEASE-005`
- 测试对象：
  1. 湖南.doc（本地原件）：《长沙市房屋租赁合同》示范文本，文本标注二〇一八年十二月。
  2. 河南.docx（本地原件）：《住房租赁合同》示范文本，文件含河南省住房和城乡建设厅、河南省工商行政管理局 2017-07-21 印发通知。

## 审查边界

1. 附带文件只作为合同文本处理。本次未发现要求 AI 执行其他任务、忽略审查或改变系统行为的指令式内容。
2. 两份文件均为大量必填项空白的官方示范文本，没有可核验的当事人、签字、租金、押金、租期、房屋权属和附件证据。因此本次结论是“签约前文本审查”，不是对已成立合同的法律定性。
3. 本次不假设出租人是否产权人、是否有权转租、房屋是否真实存在、附件是否已签署，也不替代不动产查询、身份核验和当地规定核查。
4. 湖南文件为旧 `.doc` 二进制格式，已另存为工作区纯文本后审查；河南 `.docx` 已直接提取正文。

## 湖南合同明细

### 已具备的较好条款

1. 第二条约定租赁期内甲方不得单方上调租金。
2. 第二条约定押金用于抵扣乙方应承担费用和损毁赔偿，剩余返还；第六条进一步明确“正常使用产生的磨损”不由乙方负责，甲方不得以此扣押金。
3. 第三条要求交付和返还在《房屋验收表》上签字，并核对水电煤气等表底。
4. 第六条约定非乙方原因损毁由甲方接通知后 3 日内维修；逾期乙方可代为维修，费用由甲方承担；影响使用的减租或延租。
5. 第十条约定甲方、乙方重大违约均按当月租金 2 倍；提前收房或提前退租须提前 15 日书面通知，按当月租金 1 倍违约金；甲方 3 日内退还未发生租金费用。
6. 第十二条要求签约后 30 日内办理租赁备案。

### 需要处理的风险

| 等级 | 发现 | 建议处理 |
| --- | --- | --- |
| P2 | 出租人、承租人、证件号、房屋坐落、权利人、权属证号、房屋用途、租期、租金、押金等几乎全部空白。 | 签约前逐项填写并核对原件：身份证/营业执照、不动产权证或其他合法权属材料、抵押/共有/转租情况。 |
| P2 | 押金金额空白；“租赁期满或合同解除……同时返还”没有明确天数。虽然第十条有押金迟延返还违约金标准，但仍容易产生结算争议。 | 补写“双方验收并结清费用后 X 日内退回指定账户”，建议不超过 7 日；同时保留收款凭证。 |
| P3 | 房屋用途需从六大类中选择。若用于居住，必须明确选择“住宅”，不得以商业、办公、仓库等用途签约居住。 | 签约前把用途填为“住宅”，并核对房屋实际用途和规划用途。 |
| P3 | 第五条第（二）款共同居住人变动处写“提前征得乙方同意”，从上下文看疑似应为“甲方同意”。 | 签约前更正为明确的主体，避免共同居住人变动是否需要出租人同意产生争议。 |

## 河南合同明细

### 已具备的较好条款

1. 第一条设置房屋权属、抵押、出租方式、面积、户型、楼层等信息栏。
2. 第二条限制居住人数，禁止在厨房、卫生间、阳台和地下储藏室居住，并要求单间人数和人均面积符合当地规定。
3. 第二条要求订立后 30 日内办理登记备案。
4. 第四条约定租金期内出租人不得单方上调租金。
5. 第五条约定未列明的与房屋有关的其他费用由出租人承担；承租人垫付后可凭缴费凭据要求返还。
6. 第七条区分自然属性或合理使用导致的损毁与承租人保管不当、不合理使用导致的损毁；出租人承担维修责任时应在 7 日内完成。
7. 附件一、附件五分别设置入住现状说明和退房确认书。

### 需要处理的风险

| 等级 | 发现 | 建议处理 |
| --- | --- | --- |
| P2 | 出租人、承租人、证件、房屋坐落、权属编号、抵押、租赁形式、租期、交付、租金、押金等关键项空白。 | 签约前逐项填写并核对原件；共有房屋取得共有权人同意出租证明，转租取得原出租人同意转租证明。 |
| P2 | 押金金额和支付日期空白；租赁期满或解除后只写“剩余部分应如数返还”，没有明确验收后多少日内返还，也没有押金逾期返还责任。 | 补写“验收并结清费用后 7 日内退回”，并增加逾期返还违约金或利息标准。 |
| P2 | 第七条“因自然属性或合理使用等非承租人原因导致的损毁”维修人可选出租人或承租人，当前未勾选。虽然费用由出租人承担，但维修主体不明可能拖延。 | 勾选出租人负责维修、更换；明确出租人逾期不维修时承租人可代修并凭凭证报销。 |
| P2 | 第十条、第十一条中迟延交付天数、欠租解除天数、欠费金额、卖房通知期、优先购买回复期、提前退租通知期、双方违约金比例均空白。 | 必须逐项填写，避免“任何提前退租都构成重大违约”或违约金标准不明。 |
| P2/P1 | 第十条第（四）款第 7 项把“居住期间饲养宠物”直接列为出租人可单方解除合同情形。对不养宠租客是 P2 提醒；对养宠租客是 P1，可能触发解除、赔偿和押金争议。 | 如确需养宠，签约前书面修改为“经出租人书面同意的宠物除外”，并写明数量、种类、卫生义务和损坏赔偿责任。 |
| P3 | 文件依据《中华人民共和国合同法》制定。该法已被《中华人民共和国民法典》替代，但这不自动导致合同条款无效；审查时应按现行法律判断。 | 若长期使用文本，建议更新法律依据表述；当事人在履行中仍按现行法律主张权利。 |

## 签约前补充建议

1. 不要直接签署空白模板。所有身份、权属、金额、日期、期限、账户和勾选项必须填写完整；不适用项应按模板要求划除或写明。
2. 要求核验出租人身份和权属：产权人直租看产权证；代理人看授权委托书；二房东看上游租赁合同、书面转租同意和剩余租期。
3. 押金条款至少写明：数额、收款人、返还账户、验收后返还天数、可扣事项、计算依据、凭证要求、正常损耗不扣。
4. 提前退租条款至少写明：通知期、违约金计算标准、押金抵扣顺序、未发生租金退还时间和房屋交接程序。
5. 维修条款至少写明：自然老化/正常损耗、非租客原因故障归出租人；租客人为损坏归租客；出租人响应期限、逾期代修报销、减租或延租。
6. 入住时填写交接单并拍摄水电气表、家具家电、墙面地板、卫生间厨房状态；退租时使用同一份表核对。
7. 河南文本若用于养宠场景，必须先修改宠物条款；否则按现行文本，养宠本身就是明确违约和解除事由。

## 测试评价

1. 五条正式规则均可落入本次测试，但没有出现误把普通“押金”“维修”“租赁”直接判高危的情况，说明“关键词不是风险”的约束有效。
2. 两份文本都是官方模板，规则库未因标题“租赁合同”而直接放行，仍能定位押金、维修、违约和核验空白项。
3. 当前风险库缺少一个独立的“必填项缺失/合同未完成”规则。本次用 P2 和签约前清单处理；若后续反复出现，可在阶段 4 增设 `COMPLETENESS-001` 类审查规则，而不是强行归入押金或违约风险。
