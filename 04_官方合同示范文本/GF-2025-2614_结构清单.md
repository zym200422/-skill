# GF—2025—2614《城镇房屋租赁合同（示范文本）》结构清单

- 知识库版本：V1.0（2026-09-13）
- 原始依据：[GF-2025-2614_城镇房屋租赁合同示范文本_全文.txt](04_官方合同示范文本/GF-2025-2614_城镇房屋租赁合同示范文本_全文.txt)
- 来源等级：A（国家市场监督管理总局 2025 年发布）
- 用途：作为合同审查的“标准基线”。用户合同与基线的偏差处，即风险候选点；再回到规则库找法律依据定级。

## 文本组成

| 部分 | 内容 | 审查价值 |
| --- | --- | --- |
| 使用说明 | 文本性质、20 年租期上限、备案提示、名词解释 | 基线合法性常识；优先承租/优先购买/次承租人代偿权定义 |
| 特别提示 | 出租人 4 条、承租人 3 条 | 签约前核验清单的官方版本（身份、权属、可租性、付款凭证、交割单） |
| 正文 | 第一条至第二十一条 | 逐条对照审查 |
| 附件 | 房屋交割单（生活费用底数 + 分房间物品清单 + 钥匙卡证） | 退租纠纷的证据基线，缺失即风险 |

## 正文逐条审查要点

| 合同条款 | 基线要求 | 审查要点 | 关联规则 |
| --- | --- | --- | --- |
| 第一条 房屋基本状况 | 坐落、所有权人、甲方身份类型、权属证明及编号、面积、抵押、户型装修、附属物品、车位 | 权属证明类型与编号是否留空；甲方非所有权人时凭哪种材料有权出租；是否披露抵押 | LAW-REG-004；LAW-LEASE-013 |
| 第二条 租赁用途 | 明确用途，未经同意不得变更 | 用途空白或与实际不符（办公住人、商住混用） | LAW-REG-002；LAW-LEASE-013 |
| 第三条 转租 | 明确是否同意转租；转租期不超剩余租期；擅自转租的解除选择项 | 与二房东签约时，本条 + 上游合同共同验证转租链条 | LAW-LEASE-010 |
| 第四条 租赁期间 | 起止日期、免租期、优先承租权、续租提前通知天数 | 租期超 20 年；到期后衔接约定缺失 | LAW-LEASE-003；LAW-LEASE-016 |
| 第五条 租金 | 月租金、税费承担、支付周期、收款账户、逾期解除天数 | 收款账户非房东本人/非监管账户；逾期天数过短；一次性年付 | LAW-LEASE-011；LAW-REG-007 |
| 第六条 押金 | 数额、收款凭证、终止后结清费用即全额返还、可抵扣、不足追偿 | 缺返还时间或扣减情形（对照条例必须三项齐备）；“不退”“自动没收”式条款 | LAW-REG-005；LAW-LEASE-007 |
| 第七条 其他相关费用 | 费用逐项勾选承担方；甲方欠费致停供时乙方的抵扣/解约权；乙方欠费甲代缴后从押金抵扣 | “管理费”等未标明费用；代缴后补足押金天数空白 | LAW-REG-010 |
| 第八条 交付及返还 | 交付时间、迟延交房解约权、按交割单双向验收、逾期返还违约金 | 交割单未签；自然损耗除外未写；“物品完整良好”被扩写成“恢复原状” | LAW-LEASE-006；LAW-LEASE-007 |
| 第九条 房屋使用 | 正常使用告知义务、甲方不得擅入、装修须经同意及残值分担 | 擅入条款被删除；装修残值约定偏向房东 | LAW-REG-004；LAW-LEASE-012 |
| 第十条 房屋维修 | 甲方保持正常使用状态并承担正常使用损坏的维修；可自修报销；拒不维修可解约 | 维修义务全部转嫁租客；自修需“甲方同意”被写成前置卡点 | LAW-LEASE-008；LAW-LEASE-009 |
| 第十一条 优先购买权 | 提前通知天数 + 同等条件优先购买 | 通知期限留白或被删除 | LAW-LEASE-015 |
| 第十二条 保密要求 | 双方保密义务 | 低风险；注意与个人信息收集范围核对 | 无 |
| 第十三条 甲方权利义务 | 有权出租、出示证明、无查封冻结、未设且不新设居住权、适租保持 | 权属/查封/居住权三条保证缺一即高危；居住权是 2025 文本亮点，民间合同常缺失 | LAW-REG-004；LAW-LEASE-013；LAW-LEASE-006 |
| 第十四条 乙方权利义务 | 付租押费、守法使用、物业管理、安全使用、到期返还 | 注意“乙方原因致火灾等事故由乙方担责”是否被扩写成无过错兜底 | LAW-LEASE-014 |
| 第十五条 违约责任 | 提前解约通知期 + 违约金标准；迟延交房/返还押金/返还房屋/付款的违约金标准；可预见损失上限 | 示范文本本身留空的“标准”是必填项，用户合同常被填成天文数字或“没收全部押金” | LAW-LEASE-011；LAW-REG-005 |
| 第十六条 变更终止 | 协商变更；法定终止事由；乙方六类法定解除情形；甲方三类解除情形 | 乙方法定解除权（查封/权属争议/强制性规定/危及安全）不得被删除或设额外门槛 | LAW-LEASE-013 |
| 第十七条 不可抗力 | 定义、通知、证明期限、协商变更或解除 | 证明期限空白；不可抗力被扩写至商业风险 | 无 |
| 第十八条 通知送达 | 联系方式真实有效 + 变更通知义务 | 送达条款缺失导致维权程序成本上升 | LAW-REG-012 |
| 第十九条 争议解决 | 协商；诉讼或仲裁二选一（或裁或审） | “或裁或审”条款无效风险；管辖地被设到外地 | LAW-REG-012 |
| 第二十条 附则 | 签章生效、附件同等效力、部分无效不影响其他、书面变更补充、份数 | 附件（交割单）是否实际签署；份数是否到手 | 无 |
| 第二十一条 其他 | 补充约定区 | 补充条款不得违反强制性规定，重点核对口头承诺是否落纸 | LAW-LEASE-005 |

## 与法规层的挂钩总览

- 押金条款 → 逐字对照《条例》第十条三要素：数额、返还时间、扣减情形。
- 中介环节 → 《条例》第二十五、二十六、二十七条：不代收代付、明码标价、代办备案。
- 二房东/长租公寓 → 《条例》第十九、二十条 + 民法典 716-719：转租同意、资金监管、代偿自救。
- 房屋适租性 → 《条例》第七条 + 民法典 708/712/713/731：安全标准、维修、解约。
- 到期与卖房 → 民法典 725/726/734：买卖不破租赁、优先购买、优先承租。
