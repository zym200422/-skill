# RISK-LEASE-005 合同名实不符

- 状态：正式风险，第三阶段 Step 7 转正
- 版本：V1.0
- 更新日期：2026-09-13
- 模式簇：C. 合同的问题
- 基准等级：🟠 P1
- 最高等级：🔴 P0
- 吸收草案：`RISK-DRAFT-RENT-001`

## 一、四层风险模型

| 层级 | 内容 |
| --- | --- |
| L1 现象 | 合同名为“资产管理服务协议”“房屋托管协议”“委托管理协议”“合作经营协议”等，但内容出现交付房屋、固定收益、押金、租金、租期、维修、腾退或转租安排。 |
| L2 法律问题 | 合同究竟成立租赁、委托代理、服务合作还是经营关系；谁负有交付、维修、解约、退款义务；对方是否实质从事转租经营并应受资金监管。 |
| L3 实际后果 | 租客可能误以为自己在签普通租赁，实际权利主体不清；遇纠纷时，对方可能以“这只是服务/托管/合作”否认租赁义务，导致押金、预付租金和继续居住权受影响。 |
| L4 审查动作 | 不看标题下结论，提取房屋占有与使用安排、付款结构、固定收益条款、管理权限、转租授权、维修责任、资金账户、主体身份和解除/退款机制。 |

## 二、触发条件

满足任一组即触发：

1. 合同标题含“资产管理”“托管”“委托管理”“服务协议”“合作经营”等，但正文写入租赁期限、租金或押金。
2. 一方将房屋交付另一方占有、使用、经营，另一方支付固定收益、保底收益、固定服务费或租金。
3. 名为“服务/管理费”，但费用按月、按季、按年支付，且与具体服务量无关。
4. 合同同时出现“托管”“代租”“包租”“转租”“续租”“腾退”“房屋交付”“租期届满”等租赁核心用语。
5. 对方主张自己不是出租人，但又负责收租、收押金、安排入住、维修或清退。

## 三、排除与降级条件

### 排除条件

以下情形通常不触发本规则：

1. 合同就是普通租赁，当事人、房屋、租期、租金、押金和维修责任一致。
2. 真居间/中介服务：中介只提供撮合，收取佣金，不占有房屋、不收租金押金、不承诺固定收益。
3. 真实委托代理：受托人仅按委托权限签约或管理，收益归委托人，费用据实结算，资金直接进入产权人账户。
4. 已入住后的单独保洁、维修、代收快递等服务协议，与租赁关系不冲突。

### 降级条件

1. 虽然名称偏“管理/服务”，但合同主体、收款账户和实际出租人一致。
2. 房屋交付、租期、押金、维修、解除、腾退和违约责任写得完整。
3. 企业转租经营使用公示的住房租赁资金监管账户。
4. 对方能出示产权证明、上游租赁合同和转租授权。
5. 付款周期短、金额合理，并有正式发票或收据。

## 四、加重条件

1. 合同名称与正文权利义务明显冲突，且没有解释条款。
2. 对方以“非租赁合同”回避维修、押金退还、备案、解约或监管义务。
3. 要求押金、季付、半年付、年付，但资金进入个人账户。
4. 从事包租/转租经营的企业不提供资金监管账户。
5. 无产权证明、无上游合同、无转租授权。
6. 合同削弱租客继续使用、报修、解除或退押权利。
7. 对方拒绝说明自己是出租人、代理人、受托人还是二房东。

## 五、风险等级判定

| 判定结果 | 等级 |
| --- | --- |
| 名称与实质不一致，但核心租赁要素和资金路径完整 | 🟠 P1 |
| 实质为租赁，且叠加大额预付、个人账户、无资金监管、无转租授权中任一项 | 🔴 P0 |
| 合同有名称偏差，但实质是中介撮合或真实委托代理，资金不经过对方 | 不输出风险，或仅 🔵 P3 提醒留存委托文件 |
| 名称偏差不影响房屋占有、付款、维修和解约责任 | 🔵 P3 |

## 六、法律依据

| ID | 作用 |
| --- | --- |
| LAW-LEASE-001 | 租赁合同的核心是出租人交付租赁物供承租人使用收益，承租人支付租金；不因合同名称改变实质定性。 |
| LAW-REG-004 | 出租人应出示身份证明、权属证书或其他合法出租权材料，并配合租客核验。 |
| LAW-REG-007 | 从事转租经营的住房租赁企业应设立并公示资金监管账户，通过该账户办理租金押金收付。 |
| LAW-REG-008 | 自然人转租达到经营规模的，适用住房租赁企业规定，不能以“个人”规避监管。 |
| GF—2025—2614 第一、五、六、八、十、十三条 | 官方示范文本要求写入房屋权属、租金、押金、交付返还、维修和出租人权利保证，是判断合同实质的基线。 |

## 七、案例依据

| 案例 | 对规则的支撑 |
| --- | --- |
| CASE-LEASE-0009 | 北京三中院案例：名为《资产管理服务合同》，但因交付使用、固定收益等实质内容，被认定实为租赁；无任意解除权。名称不能掩盖租赁关系。 |
| CASE-LEASE-0010 | 上游关系被清理后，次承租人逾期腾退仍可能被直接主张占用使用费。名实不清若叠加转租链条，会放大居住和资金风险。 |

## 八、审查问题清单

1. 甲方、乙方、丙方分别是谁？谁是产权人、出租人、受托人、运营方、实际收款人？
2. 对方是否出示身份证/营业执照、产权证、上游租赁合同或转租授权？
3. 房屋由谁交付给谁？租客是否获得独占占有和使用？
4. 付款名目是租金、服务费、管理费、收益分成还是合作费？如何计算？
5. 是否存在固定收益、保底收益、包租收益？
6. 押金由谁收取、由谁退还？退还条件是什么？
7. 租期、续租、解约、腾退、违约责任是否明确？
8. 维修、物业、水电、燃气、税费由谁承担？
9. 对方是否可以转租、分租、改造、重新定价或更换租客？
10. 若是企业转租经营，是否提供资金监管账户？
11. 若上游合同解除、托管方跑路或产权人收回房屋，谁负责退款、安置和赔偿？

## 九、用户后果与潜在损失

一次性暴露：

```text
押金 + 已预付租金/管理费/服务费
- 已实际居住期间对应的合理金额
+ 对方主张的恢复原状、违约金或占用费
```

持续暴露：

```text
继续居住稳定性
+ 因合同定性不清导致的维权成本
+ 真正产权人与托管方断裂后的搬迁、误工和临时住宿成本
```

说明：

1. 名实不符本身不等于对方一定违法，也不等于合同无效；风险在于权利义务被包装、拆分或规避。
2. 如果实质是租赁，租客可按租赁关系主张核心权利；但这需要依据合同内容和履行证据判断。
3. 付款周期越长、资金路径越不透明，潜在暴露越高。

## 十、建议措施

1. 要求把合同性质写清：这是租赁、居间、委托代理，还是房屋托管经营。
2. 要求明确谁享有出租权、谁承担交付、维修、解约和退押义务。
3. 收款主体、合同主体和承担义务的主体保持一致。
4. 企业包租/转租要求提供公示的住房租赁资金监管账户。
5. 不要因合同叫“服务协议”就忽略租赁条款；逐条核对租期、押金、维修、腾退、违约金。
6. 对大额预付保持克制，优先月付或短周期支付。
7. 保存合同、付款凭证、身份和权属材料、入住记录、聊天记录、收据发票。
8. 如果对方同时使用“托管”“包租”“转租”，必须联动执行 RISK-LEASE-004 的转租链条审查。

## 十一、Skill 输出示例

### P1 示例

🟠 **合同名称与实质内容需要确认**

合同名为《资产管理服务协议》，但正文约定了房屋交付、租期、押金、使用方式和到期腾退。这些内容更接近租赁关系，而不仅是服务或委托管理。

签约前应确认：谁是实际出租人；押金和服务费由谁收取、由谁退还；维修和解约义务由谁承担；对方是否具备合法出租或转租授权。

### P0 示例

🔴 **名实不符叠加资金和转租风险**

合同名为“托管服务”，实际要求你支付押金和一年租金，收款账户为个人账户，对方也未提供资金监管账户、上游租赁合同或转租授权。这里可能同时存在合同定性不清、无权转租和资金脱离监管问题。

理论暴露包括押金、已预付租金，以及上游链条断裂后的搬迁和占用费争议。建议暂停付款，先核验权属、上游合同、书面转租同意和监管账户。

## 十二、边界

1. 本规则不单独判断合同效力；无效、可解除、有效但名实不符是三个不同问题。
2. 合同名称偏租赁不是坏事；真正的问题是当事人身份、义务承担和资金路径是否清楚。
3. 只要命中二房东、包租、托管、转租链条，必须继续执行 RISK-LEASE-004，而不是只输出本风险。
